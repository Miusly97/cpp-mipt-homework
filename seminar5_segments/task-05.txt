&a - bss глобальная без значения
&b - data глобальная с начальным значением
&c - rodata глобальная константа
&d - stack локальная переменная
&e - bss статическая локальная, равна 0
&pi - stack адрес локального указателя
pi - heap указывает на память из malloc
pi+5 - heap сдвиг внутри выделенной кучи
&s - stack адрес локального массива
s - stack указывает на локальный массив
&ps - stack адрес локального указателя
ps - rodata указывает на строковый литерал
f - text код функции f
&f - text адрес кода функции
main - text код функции main
"fox" - rodata строковый литерал
